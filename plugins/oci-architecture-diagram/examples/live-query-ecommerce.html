E-commerce Platform

Architecture Services

Service Component Role
DNS Public DNS - Public Edge Subnet

Resuelve el nombre publico y envia las solicitudes hacia el punto de entrada.
WAF Web Application Firewall - Public Edge Subnet

Filtra trafico HTTP/S malicioso antes de llegar al balanceador.
Load Balancer - Primary Public Load Balancer - Public Edge Subnet

Distribuye trafico entre la capa de aplicacion y mantiene un punto de entrada estable.
Container Engine for Kubernetes Commerce Microservices - Private Application Subnet

Ejecuta los microservicios o pods de aplicacion en la subred privada.
Functions Order Functions - Private Application Subnet

Ejecuta logica puntual y asincrona sin administrar servidores.
OCI Queue Payment Queue - Private Application Subnet

Desacopla trabajos asincronos para absorber picos y reintentos.
Streaming Order Events - Private Application Subnet

Transporta eventos en tiempo real entre productores y consumidores.
Service Gateway Service Gateway

Conecta recursos privados con servicios OCI sin usar internet publico.
Oracle Autonomous Database Transaction Database - Private Data Subnet

Guarda datos transaccionales o vectoriales administrados por la plataforma.
Object Storage Product Images Bucket - Private Data Subnet

Almacena objetos, archivos estaticos, documentos o respaldos usados por la solucion.
Vault Secrets Vault - OCI Platform Services

Protege secretos, claves y material criptografico.
Bastion Private Admin Access - Operations Subnet

Permite acceso administrativo temporal y auditado a recursos privados.
Logging Central Logging - OCI Platform Services

Centraliza logs para auditoria, diagnostico y trazabilidad operativa.
Monitoring Service Monitoring - OCI Platform Services

Recolecta metricas y senales de salud para alertas y observabilidad.
